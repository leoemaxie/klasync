# KLASYNC visual direction

KLASYNC uses the supplied ORYZO reference as an editorial visual system, not as a product or copy template. The learning experience remains calm, factual, accessible, and task-focused.

## Non-negotiable tokens

| Token | Value | Use |
| --- | --- | --- |
| Warm Cream | `#ffedd7` | Foreground text and interactive borders |
| Walnut Shadow | `#100904` | Primary canvas |
| Bark Brown | `#382416` | Elevated surface and restrained filled action |
| Cork Border | `#40372e` | Dashed structural dividers |
| Driftwood | `#6c5f51` | Supporting labels |
| Ember Accent | `#dc5000` | Rare editorial/status emphasis only; never the primary CTA |

Use the display family at weight 500 with uppercase labels and headings. Descriptive learning copy may use weight 400, mixed case, and a larger readable size. Avoid shadows, white/black surfaces, dense cards, and bright CTA colors. Sections should feel spacious and editorial, while live captions must remain immediately legible.

## Interaction rules

- Prefer underlined text links and outlined ghost controls.
- Keep filled actions rare and Bark Brown only.
- Use underline-only inputs where practical.
- Preserve keyboard focus, semantic labels, sufficient contrast, and reduced visual noise on the live-learning view.

## Package manager

Use `pnpm` / `pnpm.cmd` exclusively. Do not use npm or add a `package-lock.json`.
